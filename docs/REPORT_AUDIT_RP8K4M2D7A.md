예상하지 못한 TypeError 등 프로그래밍 오류를 일괄 무시하지 않습니다. 네이버 401/403 등 영구 HTTP 오류는 재시도하지 않으며, timeout/연결 오류·429·500/502/503/504만 최대 3회 시도합니다. 비밀값이 포함될 수 있는 요청·헤더·원래 예외 본문은 오류 메시지에 넣지 않습니다.

## 실제 원자료 대조

크래프톤 2026년 반기 공시 `20260814003894`에서 다음을 확인했습니다.

- 손익 3개월 순이익: **-29,900,848,684원**.
- 손익 누적 및 공시 원문 CF 반기 순이익: **484,194,572,225원**.
- CF API가 반환한 3개월 순이익을 그대로 사용하면 약 **5,140.95억 원** 차이가 발생합니다.
- 원문 확인된 누적 순이익을 사용한 영업현금흐름 조정 합: **458,676,015,045원**.
- 공시 영업현금흐름 총액과 차이: **0원**.

이는 확인된 API 값의 기간 불일치이며 기업의 회계 부정 증거가 아닙니다. 원문 확인은 중간재무제표 CF 순이익 충돌에 한정됩니다. 모든 계정의 XBRL 정합성을 검증하는 엔진은 아닙니다. 표가 모호하거나 원문을 확인하지 못하면 보정값을 추정하지 않고 `null` 및 `unresolved_period_conflict`로 남깁니다.

ECOS 실제 조회에서 환율과 M2가 정상 반환됐습니다. 월간 관측 기간을 오늘의 수치나 발표일로 오인하지 않으며, 과거 시점 분석에는 현재 수정 통계를 제공하지 않는 기존 정책을 유지합니다.

뉴스 실패의 최초 로그에는 HTTP 상태나 예외 유형이 없었습니다. 같은 요청을 재실행했을 때 HTTP 200으로 성공했으므로, 당시의 정확한 외부 실패 원인을 사후 확정할 수 없습니다. timeout을 주입한 실제 ToolNode 경로에서 기존 전체 중단을 재현하고 수정 후 명시적 자료 부재로 정상 반환됨을 확인했습니다.

## 유지되는 한계

- 한국판 매크로 기본 범위는 ECOS 국내 5개 지표입니다. 미국 국채·미국 주가지수·유가는 기본 수집 대상에 추가하지 않았습니다.
- Naver는 검색 요약과 제한된 검색 창을 제공하며 완전한 뉴스 아카이브가 아닙니다.

- 이번 실행에서 Polymarket은 HTTP 451로 접근 불가였습니다. 우회하지 않고 확률 자료 부재로 남깁니다.
- 기업별 목표주가·컨센서스 데이터 공급자는 추가하지 않았습니다. 기술적 관찰 가격을 가치평가 목표가로 대체하지 않습니다.
